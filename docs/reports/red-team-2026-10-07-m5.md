| # | Sev | Lens | Finding | Disposition |

| F1 | HIGH (2) | Bach | The view titled the month from the **requested** month while `MonthReadout.month` is source data — a misbehaving source returning different month data would be silently relabelled (a September title over October prayers). | **Fixed:** the model now validates `readout.month == requested` before entering Ready; a mismatch fails loudly with the reason verbatim, pollutes no cache entry, and a durable test pins it (`month_mismatch_from_source_fails_loudly`). | F3 | MEDIUM (1) | Ramsay | The adapter's 3-way `tokio::join!` (conf + adhan month + iqama month) has no network-level test: mapping and use-case validation are covered, join behavior is not. | Disclosed: same disposition as M4's debounce gate — the fake-server e2e seam lands in M6 (issue #6). |
| F4 | LOW (0.5) | Linus | Day-row assembly is O(n²) (`find` per day number over 1..=max). | Accepted: n ≤ 31 + dropped days; microseconds per redraw, redraws are 1 Hz + keypress. |
| F5 | LOW (0.5) | Ramsay | Cursor/today-row highlight *styles* unasserted at render tier (content smokes only); behavior (cursor init on today, clamping) is model-covered. | Accepted: same smoke-tier rationale as M4 F5. |

Checks that came back clean:
- Cache acceptance walked three ways: hit emits zero commands
  (`month_loaded_caches_and_cursors_today`), stale/misaddressed loads are
  discarded (`stale_month_result_discarded`,
  `month_loaded_for_other_mosque_discarded`), and a failed month is not
  cached (`month_mismatch…` navigates back to a fresh `LoadMonth`).
- 12→1 / 1→12 wrap verified with cache interaction accounted for.
- HOSTILE-INPUT-TOTAL sweep: no unwrap/expect/unchecked indexing on external
  data in new code; `month()` extraction from `MonthState` is total; the
  only `unwrap_or`s are on model-internal invariants with sane fallbacks.
- Dropped days: rendered as dimmed `·` rows interleaved at their day number
  and listed verbatim in the info line (`dropped: 15`) — matching the
  crate's explicitly-listed contract, plus M2's `map_month` ct re-run.
- Layering: `views/month.rs` imports application + domain only; no new
  `mawaqit_api` references outside `infrastructure/`.

Known-accepted notes (not findings): rapid Left→Right can duplicate one
in-flight month fetch (last write wins in the cache — harmless); the month
cache is unbounded per session but bounded in practice (≤ 12 entries per
mosque).

Weighted total: 2+1+1+0.5+0.5 = 5.0 (≥ 3 required).

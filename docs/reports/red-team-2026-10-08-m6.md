# Red team — M6 offline fallback & polish (2026-10-08)

Lenses: Linus (loop/overlay correctness), Ramsay (tier coverage), Bach
(assertion honesty) — per CAMPAIGN.md Phase D, minimum 3 weighted findings.
Provenance note: this lane's implementation arrived as work-in-progress in the
working tree (parallel session); the review below covers that WIP **and** the
final tree, and every finding was fixed before landing. GitNexus via CLI
fallback (ruflo + GitNexus MCP servers absent from this session's tool list).

| # | Sev | Lens | Finding | Disposition |
|---|-----|------|---------|-------------|
| F1 | HIGH (2) | Bach | Two e2e tests asserted less than their names claimed. `offline_retry_is_performed_through_the_shared_performer` built a fake it never used (a fresh one went into the loop) and asserted no call counts; `month_navigation_and_cache_at_the_loop_tier` promised cache evidence ("cache answers the return trip without a new port call") but only asserted the month number — a retry storm or a cache-refetch regression would have passed both. Completion theater in the exact tier M6 exists to repair. | **Fixed:** both tests now pin the port-call counters (`today_calls == 3`, `month_calls == 2`) against the same Arc the loop uses. |
| F2 | HIGH (2) | Linus | Ctrl-C with the help overlay open closed the overlay instead of quitting — spec R3 says Ctrl-C *quits*, and the overlay was swallowing the global escape hatch exactly while a full-screen reference was up. The overlay title even advertised "any key closes (Ctrl-C quits)", contradicting the implemented close-set. | **Fixed:** the help branch quits on `is_force_quit_key`, closes only on `?`/Esc, swallows the rest; the title now matches the spec (`? / Esc closes · Ctrl-C quits`); pinned by `help_swallows_keys_except_close_and_quit`. |
| F3 | HIGH (2) | Ramsay | The WIP carried **zero** ut tests for the new model policies (spec R2–R4 said "model-tested"): offline retention, the 30th-tick retry boundary, `r` semantics, help overlay behavior — all reachable only through two e2e arcs. A boundary off-by-one in the retry loop would have been invisible at the unit tier. | **Fixed:** 13 ut tests added — retention + verbatim badge, first-boot failure stays honestly Failed, badge cleared on success, `r` per state (retained data not blanked; inert without selection), exact 30th-tick boundary (with the priming tick accounted), retry preconditions, help toggle/swallow/quit from every screen, plus 3 render smokes (badge over last-good, loading skeletons, keybinding table). |
| F4 | MEDIUM (1) | Linus | `runtime::run`'s command match is now asymmetric: `Search` (debounce) and `SaveSelection` (sync I/O) stay inlined while `LoadToday`/`LoadMonth` route through `perform`. | Accepted, documented at the arm: debounce is *timing* policy and save is sync-by-design (ADR-0002 §5); `perform` owns the event mapping for both tiers, so semantics cannot drift — only execution timing differs, which is the live loop's legitimate job. |
| F5 | LOW (0.5) | Ramsay | `snapshot::cache_dir`'s unit test pins path composition only; TTL/year-rule/sanitize semantics live in `mawaqit-api` 0.6.0 and are untested here. | Accepted: re-testing the crate in the TUI would duplicate its suite (no-duplication rule, ADR-0003 §1); the e2e tier covers the app-relevant arc. |
| F6 | LOW (0.5) | Linus | Skeleton rows rebuild a `Vec<Constraint>` every frame during loading. | Accepted: loading frames are transient by definition; allocation cost is trivial at 1 Hz redraw. |

Checks that came back clean:
- HONESTY: the offline badge renders **over retained last-good data**
  (`offline_badge_renders_over_last_good` asserts both); first-boot failure
  without snapshots stays `Failed(reason)` — never a badge over an empty
  screen; loading skeletons make "loading" visibly distinct from "done".
- HOSTILE-INPUT-TOTAL: badge/skeleton geometry uses `saturating_sub`/`min`
  (no panic on tiny terminals); no unwrap/expect/indexing on external data
  in the new code.
- LAYERING: `snapshot.rs` and the adapter remain the only `mawaqit_api`
  importers; help/view code imports application + domain only.
- Quit single-sourcing preserved: the help branch reuses
  `is_force_quit_key` (the F2 fix), not a third Ctrl-C definition.
- e2e seam design (ADR-0003 §5): `perform` is the single command→event
  match; `run_scripted` drives boot → quiescence-drain → scripted event
  with the same use cases — the M4-F3 runtime-gate debt is now covered at
  the loop tier (`today_calls`/`month_calls` counters).
- proptest regression file from the new HH:MM iff-shape property is
  committed alongside the suite.

Weighted total: 2+2+2+1+0.5+0.5 = 8.0 (≥ 3 required).
